# Segundo Projeto da Disciplina de Sistemas Digitais

A proposta deste projeto é implementar uma Mini CPU utilizando a linguagem Verilog. O sistema será capaz de armazenar valores em uma memória e utilizá-los para realizar operações aritméticas por meio de uma Unidade Lógica e Aritmética (ULA) interna. O nome da operação, o resultado obtido e o respectivo endereço de memória atrelado a ele serão exibidos no display LCD presente na placa.
O objetivo deste trabalho é consolidar e aplicar os conhecimentos adquiridos nas disciplinas de Sistemas Digitais e Laboratório de Sistemas Digitais durante esta reta final do período.
